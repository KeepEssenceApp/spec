# 接入一个助手

给用户照着做的步骤。「助手设置 → 接入一个助手」里显示的就是这一页的内容。

每个产品都是同一件事：把接入地址填进它那边，它打开 本产品 的允许页，你点「允许」。

- 接入地址：`https://keepessence.app/mcp`。所有人相同，不是凭据。
- 允许页上给这个助手起个名字，勾选它能干的步骤。
- 接好之后它出现在「助手设置」里，随时可以撤销。

## 对话型助手：只做深入对话

### Claude

1. 打开 Claude 的 Connectors，点 Add → Add custom connector。
2. 名字填 本产品，地址粘贴接入地址，点 Continue。
3. 认证保持它自动检测到的选项，点 Add，再点 Connect。
4. 浏览器打开 本产品 的允许页，点「允许」。

各套餐都能接；免费套餐只能有一个自定义连接器。Claude 第一次存回笔记时会问你是否允许。

### ChatGPT

1. 在电脑上打开 `chatgpt.com/plugins`，点 + → Add custom MCP server。
2. 名字填 本产品，Server URL 粘贴接入地址，认证选 OAuth。
3. 看过风险提示后确认，点 Create as a plugin，再安装它。
4. 浏览器打开 本产品 的允许页，点「允许」。

只能在网页上接和用，手机上不行。个人套餐只能读：聊完后在 本产品 的这次深入对话上点「把结果贴回来」。Business、Enterprise、Edu 能直接存回，每次会让你确认。

### Gemini

1. 在电脑上打开 `gemini.google.com` → Settings → Connected Apps。
2. 在 Custom apps 下点 Add a custom app，粘贴接入地址，点 Next。
3. 浏览器打开 本产品 的允许页，点「允许」。
4. 之后手机和网页都能用：对话里输入 `@` 选 本产品。

目前只限美国、18 岁以上、个人 Google 账号、英文，并且要开着 History。存回笔记时 Gemini 每次都会让你确认。

## 定时型助手：解读、汇总、深入对话

### 自己部署的 agent

1. 在它的 MCP 配置里加一个远程服务器，地址填接入地址，传输选 Streamable HTTP，认证选 OAuth。
2. 它打开 本产品 的允许页，点「允许」。
3. 给它设一个定时任务：每次来先问有什么活，认领，做完交回。

## 怎么深入对话

- 从助手那边：对它说「深入今天每日摘要里讲某某的那条」。它从 本产品 取到那一条，开始聊。
- 从 本产品 这边：在一份解读或每日摘要的一条上点「深入对话」，选加入队列先精读，或现在去深入对话，再选用谁。现在去时，本产品 打开那个助手并填好开场话；不能自动打开的，复制开场话过去发出。
- 加入深读队列：定时型助手下次来取活时先精读这一条，读好了在「笔记」页最上面等你。对话型助手做不了精读。
- 深入对话的时候可以让助手再去查，或者做它那边预先配好的事。那是助手那边的事，本产品 看不到，也不管。
- 聊完说「存成笔记」。助手不能存的，回 本产品 点「把结果贴回来」。没有笔记存回来也没关系：这一条留在深读队列里，可以再去，也可以移出。

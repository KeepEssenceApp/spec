# v1.0 内测验收标准

状态：2026-11-24 定。v1.0（第一期）能开内测，以这一页的每一条都通过为准。范围取自 [platforms](platforms.md#v10-的范围) 和 [techspec](techspec.md#1-第一期范围)；这一页只写怎么验、验到什么算过。

说「通过」必须写明在哪验的（规则 E2）：`自动`（仓库里的自动测试）、`线上`（对着 keepessence.app 的真实请求）、`真机`（写明哪台设备）。没验的照实写「没验」。

## 0 目标

一个受邀用户，从拿到邀请到留下第一篇笔记，全程走得通，并且不依赖任何人工干预：

1. 用邮箱验证码登录，这台设备成为他的第一台管理档设备。
2. 在手机、浏览器扩展、网页收件箱任一处存入一条。
3. 几分钟内，内置的分派助手完成初筛，内置的工作助手交回四项解读。
4. 当天 21:00 之后，工作助手出一份每日摘要；他读完按「读了，晚安」。
5. 他把一条加入深挖队列，接入自己的助手（MCP），在助手那边深挖，存回一篇笔记。
6. 月历上那一天变成金色。

`effort`（400）、重发收到付费答复、回收前没写结果 → 第 2 轮后预算花完，第 3 个 Cron 不再问，当天 `gave_up`，一共 4 个请求，不是 16 个；**没有用量的两种答复分开验**：「HTTP 200、有文本、没有用量」和「没文本或拒答、也没有用量」各一条，都是这次尝试的失败、不补问、不占付费答复预算、费用未知 +1、不把用量记成 0（现在的核心对前一种造一个 0 | W6 | 网页存入：「今天」底部一个大的「从剪贴板存入」和一个小的输入按钮；输入的弹层手机上从底部升起、宽屏在按钮旁，键盘不遮「存入」；可以选文件、拖入图片；一个动作存入，完成时顶部一句话；像密码的内容先问；弹层只在点了按钮之后打开 | 自动（电脑、手机视口）+ 真机 |
| W7 | 手机上一条解读可以左右滑：往右加入深挖队列，往左不感兴趣 | 真机：iPhone、安卓 |
| W8 | 视觉符合品牌定义：黑、白、纸、灰，金只给留下来的东西（金色的字用 `--ke-gold-ink`），红只给会丢东西的事；没有绿和黄；圆角只用色表里的 0/8/14/20/28 和胶囊；浅色深色都有；字和底的对比度不低于 4.5:1；可按的东西不矮于 44 px | 自动：样式表里的颜色和圆角全部出自色表；截图人工看一遍 |
| W14 | 页面不比屏幕宽：320 到 430 px 的手机宽度上，每个页面、弹层打开时、带很长不断词的内容，页面都不能左右拖动 | 自动（Chromium）；WebKit 和真机各看一遍 |
| W9 | 界面用词全部出自词表；「不用的词」一个都不出现 | 自动：文本检查 |
| W10 | 可以加到主屏幕；安卓上出现在系统的分享菜单里，分享过来直接存入 | 真机：安卓；iPhone 验加到主屏幕 |
| W11 | 界面上不出现凭据：没有可看、可复制、可手填的令牌 | 自动 + 人工 |
| W12 | 视频条目：「正在读视频里的话…」；「识别出来的文字」一块和淡字说明；没话语、太长、没取到各一句；列表、卡片、每日摘要、通知不带识别出来的文字；中英文都有 | 线上 + 真机 |
| W13 | 账户页：界面语言、「总用我的语言」开关（缺省关），旁边一句说明：新写的解读和每日摘要用什么语言，已经写好的不翻译；中英文都有；读档看不到这个页 | 线上 |
| W15 | 每日摘要页和状态栏遇到不认识的 `no_digest_reason`：写通用的那句，不写原因行，页面和控制台不出错；认识 `gave_up`，请求 `GET /v1/status` 时带 `digest_reasons=gave_up`，读到它写「今天没生成出来」（中英文都有）；请求条目带 `unavailable_reasons=analysis_failed`，读到 `unavailable: true` 用 `summary` 区分「没取到内容」和「没解读出来」，不写固定的一句 | 自动（用 fake core 给不认识的值、给 `gave_up`、给 `null`、给两种 `unavailable: true`，看页面和控制台） |
